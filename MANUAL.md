## ⚙️ Installation & Setup

### For End-Users (The Easy Way)
1. Navigate to the **Actions** tab in this repository.
2. Select the latest successful **Build**.
3. Under 'Artifacts', download `Aadi-Vayu-Executable`.
4. Run the `.exe` file. No Python installation required.
